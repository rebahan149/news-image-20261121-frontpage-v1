# The Day in One Page — Saturday 21 November 2026

A one-page broadsheet summing up the world's news of **Saturday
21 November 2026** in **35 stories** across 7 regions, built for the
make.fun [news-image-20261121](https://make.fun/bounty/news-image-20261121)
bounty. Every panel carries an original flat illustration drawn for
this page.

Three hero stories lead — COP31 running into overtime in Antalya with
no deal and a draft that never mentions fossil fuels, a Russian
missile landing on Polish territory as Warsaw turns to NATO, and the
overnight barrage that killed 12 and wounded 82 across Ukraine —
followed by a by-the-numbers strip (0 deals, 900K AI chips cleared for
China, $48.3bn of US war costs, Starc's 7/58 at Perth), ten more
numbered illustrated panels, a dotted world map with the drawn stories
pinned, and 22 briefs. A DATE CHECK box states the rule the page was
edited by: every story happened or was first reported on Saturday
21 November 2026 — Friday's $7.25bn Roundup settlement approval,
Friday's Kyiv bridge strikes and Thursday's Shenzhen declaration are
named as excluded.

## Files

- `entry.png` — the judged image (1024×1024 PNG, under 1 MiB)
- `index.html` — the front page source (illustrations are inline SVG)
- `main.py` — copies `entry.png` to the output directory and prints a one-line dossier
- `STORIES.md` — the per-story verification record

## Run

```sh
python3 main.py
```
